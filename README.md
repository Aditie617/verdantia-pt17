
# Verdantia 🌿

Verdantia is a calming plant-themed web application designed to help users explore beautiful indoor and outdoor plants with care information, scientific names, and interactive plant cards.

## Features

- 🌱 Responsive modern UI
- 🔍 Plant search and difficulty filter
- 🪴 Interactive plant cards
- 📖 Popup modal with:
  - Scientific name
  - Care instructions
  - Difficulty level
- 🍃 Animated hanging vines
- 🎨 Aesthetic botanical design
- 📱 Mobile-friendly layout

## Tech Stack

- HTML5
- CSS3
- JavaScript
